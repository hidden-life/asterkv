# AsterKV v0.1.0
AsterKV v0.1.0 is the first runnable single-node foundation release.

This release validates the initial client/server slice:
```text
asterd
    -> TCP server
    -> line-based custom protocol
    -> command dispatcher
    -> in-memory storage

astercli
    -> local mode
    -> TCP single-command mode
    -> TCP REPL mode
```

## Release scope
AsterKV v0.1.0 includes:
- `asterd` server binary;
- `astercli` command-line client;
- custom line-based protocol foundation;
- TCP server foundation;
- TCP client foundation;
- in-memory key-value storage;
- command pipeline;
- server config file support;
- configurable server log level;
- `spdlog`-backed logging facade;
- TCP integration smoke tests.

## Supported commands
The release supports:
```text
PING
GET
SET
DEL
EXISTS
```

## Server
Start the server:
```bash
./build/debug/apps/asterd/asterd --listen 127.0.0.1:7721
```

Start with explicit runtime options:
```bash
./build/debug/apps/asterd/asterd --listen 127.0.0.1:7721 \
    --max-clients 128 \
    --idle-timeout 300 \
    --log-level info
```

Start from config:
```bash
./build/debug/apps/asterd/asterd --config config/asterd.conf
```

## Client
Single-command TCP mode:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 PING
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 SET username alex
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 GET username
```

TCP REPL mode:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721
```

Local mode:
```bash
./build/debug/apps/astercli/astercli --local PING
```

## Protocol response examples
```text
+PONG
+OK
$4
alex
:1
-ERR not_found key not found
-ERR invalid_argument unknown command
```

## Configuration
Example:
```ini
listen = 127.0.0.1:7721
max_clients = 128
idle_timeout_seconds = 300
log_level = info
```

## Logging
The server uses the `AsterKV::Logging` facade backed by `spdlog`.

Supported levels:
```text
debug
info
warn
warning
error
critical
off
```

## Testing
Run full validation:
```bash
rm -rf build/debug

cmake --preset debug
cmake --build --preset debug
ctest --preset debug --output-on-failure
```

Run client/server integration tests:
```bash
ctest --preset debug -R "asterd_tcp|astercli_tcp|asterd_config_tcp" --output-on-failure
```

## Current limitations
AsterKV v0.1.0 intentionally does not include:
- persistent storage;
- WAL;
- snapshots;
- replication;
- Raft;
- clustering;
- authentication;
- TLS;
- binary protocol;
- async event loop;
- worker pool;
- persistent TCP client sessions;
- pretty response rendering;
- command history or autocompletion in `astercli`;
- production-grade observability;
- benchmarks.

## Next milestone
The next development milestone after v0.1.0 should focus on strengthening the single-node
foundation before distributed features.

Candidate areas:
- response rendering for `astercli`;
- persistent client connection support;
- storage API hardening;
- command semantics cleanup;
- WAL planning;
- benchmark foundation.
