# AsterKV v0.2.0 Release Checklist

## Scope

AsterKV v0.2.0 is the CLI response rendering and client UX foundation release.

## Required components

- [ ] Project version is `0.2.0`.
- [ ] `AsterKV::Client` module builds successfully.
- [ ] Client response parser tests pass.
- [ ] Client pretty renderer tests pass.
- [ ] `astercli --local` prints pretty output.
- [ ] `astercli --connect <host:port> <command>` prints pretty output.
- [ ] `astercli --connect <host:port>` REPL prints pretty output.
- [ ] Protocol errors print to stderr.
- [ ] Protocol errors return exit code `1`.
- [ ] Successful responses print to stdout.
- [ ] Successful responses return exit code `0`.
- [ ] REPL `help` works.
- [ ] REPL `?` works.
- [ ] REPL `exit` works.
- [ ] REPL `quit` works.
- [ ] REPL empty lines are ignored.
- [ ] REPL EOF/Ctrl+D exits gracefully.

## Explicit non-goals

- [ ] No public `--raw` mode was added.
- [ ] No storage durability feature was added.
- [ ] No WAL feature was added.
- [ ] No persistence claim was added to release docs.

## Required validation

Clean build:

```bash
rm -rf build/debug

cmake --preset debug
cmake --build --preset debug
```

Full tests:
```bash
ctest --preset debug --output-on-failure
```

Focused tests:
```bash
ctest --preset debug -R "astercli|asterkv_client_tests|astercli_tcp_repl" --output-on-failure
```

Check no public raw mode:
```bash
grep -R -- "--raw" apps include src tests docs README.md CHANGELOG.md || true
```

Expected result: empty output.

## Manual checks
Start server:
```bash
./build/debug/apps/asterd/asterd \
    --listen 127.0.0.1:7721 \
    --max-clients 8 \
    --idle-timeout 30 \
    --log-level warn
```

Successful command:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 PING
echo $?
```

Expected:
```text
PONG
0
```

Protocol error:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 GET missing_key
echo $?
```

Expected:
```text
error: not_found key not found
1
```

REPL success:
```bash
printf 'help\nPING\nquit\n' | ./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721
echo $?
```

Expected exit code:
```text
0
```

REPL with protocol error:
```bash
printf 'GET missing_key\nquit\n' | ./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721
echo $?
```

Expected exit code:
```text
1
```

- [ ] Working tree is clean before tagging.

- [ ] Final validation passes on `main`.
