# AsterKV v0.3.0 Release Checklist

## Scope

AsterKV v0.3.0 is the storage durability planning and WAL foundation release.

## Required components

- [ ] Project version is `0.3.0`.
- [ ] `AsterKV::Wal` module builds successfully.
- [ ] WAL record model exists.
- [ ] WAL record validation exists.
- [ ] WAL record serialization exists.
- [ ] WAL record deserialization exists.
- [ ] `AKVWAL1` serialized format is documented.
- [ ] WAL file writer exists.
- [ ] WAL file reader exists.
- [ ] WAL replay helpers exist.
- [ ] WAL-backed storage exists.
- [ ] `WalBackedStorage` implements `StorageEngine`.
- [ ] `asterd --wal-file <path>` exists.
- [ ] `wal_file` config option exists.
- [ ] Startup recovery from WAL file works.
- [ ] TCP `SET` writes WAL when WAL is configured.
- [ ] TCP `DEL` writes WAL when WAL is configured.
- [ ] WAL recovery integration smoke test exists.

## Explicit non-goals

- [ ] No production durability guarantee is claimed.
- [ ] No fsync guarantee is claimed.
- [ ] No checksum validation is claimed.
- [ ] No snapshot feature is claimed.
- [ ] No compaction feature is claimed.
- [ ] No replication feature is claimed.
- [ ] No Raft feature is claimed.

## Required validation

Clean build:

```bash
rm -rf build/debug

cmake --preset debug
cmake --build --preset debug
```

Full tests:
```bash
ctest --preset debug --output-on-failure
```

Focused tests:
```bash
ctest --preset debug -R "wal|config|server|asterd_wal_recovery" --output-on-failure
```

## Manual WAL recovery check
Start server:
```bash
rm -f /tmp/asterkv_v030_manual.wal

./build/debug/apps/asterd/asterd \
    --listen 127.0.0.1:7721 \
    --max-clients 8 \
    --idle-timeout 30 \
    --log-level warn \
    --wal-file /tmp/asterkv_v030_manual.wal
```

Write value:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 SET username alex
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 GET username
```

Expected:
```text
OK
alex
```

Restart server with the same WAL file.

Read value:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 GET username
```

Expected:
```text
alex
```

Delete value:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 DEL username
```

Restart server again.

Check value is missing:
```bash
./build/debug/apps/astercli/astercli --connect 127.0.0.1:7721 GET username
```

Expected:
```text
error: not_found key not found
```
